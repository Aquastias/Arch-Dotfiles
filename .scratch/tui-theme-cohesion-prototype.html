Terminal theme cohesion — ANSI-16-first prototype

Every pane below reads only the 16 ANSI slots + accent. Click a palette: it rewrites just those ~20 CSS variables and all panes repaint together. That is the whole architecture — on wl-roots Noctalia rewrites kitty's 16-color table and every TUI follows live; under KDE nothing rewrites it, so it stays on the seeded Catppuccin Mocha Sapphire.

Palette

Switching a non-default palette simulates noctalia msg color-scheme-set on a niri/Hyprland session → kitty's ANSI table is rewritten → every TUI repaints. KDE never runs the template, so on KDE only "Catppuccin Mocha Sapphire" ever shows.

Why this can't break what's built: the panes touch --c0..--c15 / --bg / --fg / --accent / --surface* and nothing else — the exact contract kitty already exposes. Bringing eza/lazygit/yazi in means pointing each at those same ANSI slots (a static stowed config), not a new Noctalia template and not a new seed point. kitty/zsh/pi templates, the Sapphire seed (ADR 0109), and KDE isolation (ADR 0104) are untouched.  ·  Throwaway prototype — capture to a branch, don't ship.
