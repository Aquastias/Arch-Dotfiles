Retry + fallback

I'll wrap the call and degrade gracefully. See the providers doc (pi.dev/docs/latest/providers).
  • bounded retries = 3, exponential backoff
  • fall back to duckduckgo on exhaustion
Note: searxng lives at 127.0.0.1:8080 (User Core).
// web-access: searxng first, ddg fallback
export async function search(q: string): Promise<Result[]> {
  for (let i = 0; i < 3; i++) {
    try { return await searxng("http://127.0.0.1:8080", q); }
    catch { await sleep(250 * 2**i); }
  }
  return duckduckgo(q); // keyless fallback
}
