Core-less, flat, additive model PROTOTYPE · throwaway

Question: drop the Core layer and the host program lane — a host just names users, each user declares its own flat, additive program list, extending from nothing. Simpler to read one user; but watch the two costs it surfaces: duplication of a shared base across every user, and homeless machine daemons (gamemode, ccache) that no single user owns.
