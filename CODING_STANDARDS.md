# Coding Standards

The judgement calls a reviewer checks in a diff. Mechanical rules are left
to the lints the pre-commit gate runs ([ADR 0156]) — readability names,
sizes and tool tiers, ADR links, doc paths, no Python, raw config reads,
shellcheck — so skip anything those already enforce.

## Installer code (`.installer/`)

- **Reads without decoding** ([ADR 0153]): names say what the thing is,
  `main()` reads as the script's table of contents, a file's header `Used
  by:` line is true. Rules beyond the lint: [readability.md].
- **Comments keep only the non-obvious why** plus its `(ADR NNNN)` anchor;
  code restatement and ADR re-arguing are cut: [comment-style.md].
- **Helpers live once, in the right world.** A new helper that duplicates a
  Commons one, or one merged across an execution-context boundary (host vs
  chroot vs guest), is a finding: [shell-commons.md].
- **Frozen strings stay frozen**: host-profile keys, CLI flags, outside env
  vars, target paths and grepped strings are never renamed
  ([readability.md] § Frozen).

## Decisions and docs

- **A new decision carries an ADR** in the same change; a change against an
  existing ADR says so or amends it ([domain.md]).
- **Package / config / service choices trace to a fetched Arch Wiki page**
  ([arch-wiki.md]).
- **Docs move with the code**: a renamed concept updates `CONTEXT.md`; a
  changed command, verb or flag updates the agent doc that documents it.
- **Layout**: one `.claude/`, `.sh` on tooling scripts ([conventions.md]).
