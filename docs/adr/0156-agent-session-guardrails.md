# ADR 0156: Agent session guardrails

## Status
Accepted — implemented. Extends [ADR 0153] (the Readability Lint) and
[ADR 0145] (the opt-in pre-push gate).

## Context
A retrospective over 35 agent sessions found mistakes no check caught:

- **Sleep polling.** 752 foreground `sleep N; tail <task output>` calls,
  ~44 h asleep, though a background task re-invokes the agent on exit.
- **No commit-time gate.** Agents commit but never push, so the pre-push
  gate ([ADR 0145]) never runs for them, and `core.hooksPath` was unset
  anyway. Lint violations surfaced only when a later run of the suite
  tripped on them.
- **Doc drift.** Agent docs named moved or deleted files (`tools/pick.sh`,
  `vm/seed-generator.bats`) and a stale "no `/dev/kvm` on this box" that
  made an agent skip a required VM install.

## Decision
- **Sleep-poll hook.** The seeded Claude config registers a `PreToolUse`
  hook (`scripts/block-sleep-poll.sh`) that blocks a foreground Bash
  `sleep` of 60 s or more and points at the background-task
  notification. Short sleeps in bounded `until` loops and
  `run_in_background` commands pass.
- **Pre-commit gate** (`.githooks/pre-commit`): the Readability Lint, the
  No-Python Lint and the Raw Config Read Lint (seconds, whole repo), plus
  shellcheck on the staged `.installer/` shell files only (the full pass
  takes minutes and stays in `run.sh`). `SKIP_LINTS=1` skips one commit.
  It rides the same `core.hooksPath .githooks` as the pre-push gate.
- **`doc-path` rule** in the Readability Lint: every backticked repo path
  in a linted doc must be a tracked file (or the tail of one). ADRs are
  exempt — history keeps old names. A removed file is named without
  backticks.

## Considered alternatives
- **A steering line asking agents not to poll.** Rejected: the harness
  already says so and the polling continued; a hook is deterministic.
- **Full shellcheck at commit.** Rejected: ~2 min per commit.
- **CI.** Deferred: the repo has no CI runner; the hooks cover the agent
  path locally.

## Consequences
`core.hooksPath` is still set per clone (the installer does not set it,
which would also turn the pre-push gate on everywhere). A doc that names
a file must be updated in the same commit that moves it.
