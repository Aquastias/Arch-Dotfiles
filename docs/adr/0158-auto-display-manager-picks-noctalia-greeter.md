# ADR 0158: `auto` picks noctalia-greeter on KDE-free Noctalia hosts

## Status
Accepted — implemented (noctalia-greeter 1.6.0 landed in `extra`).
Amends the `auto` rule of [ADR 0091]; keeps [ADR 0069]'s operator choice.

## Context
Noctalia is the shared niri/Hyprland shell ([ADR 0097]). Its sibling,
noctalia-greeter, is a greetd greeter with a bundled wlroots compositor and
the shell's visual language. Today `auto` gives a KDE-free set greetd +
tuigreet ([ADR 0091]).

Arch Wiki grounding: greetd (enable `greetd.service`; the greeter is the
`[default_session]` `command`, run as the `greeter` user by default) and
pacman (`NoExtract` skips files from being installed). Neither page covers
noctalia-greeter; its facts come from upstream docs and source.

Upstream source shows the greeter's session scan **hardcodes**
`/usr/local/share` and `/usr/share` (plus `XDG_DATA_DIRS`), deduped by
`Name=` with /usr/local first, skipping `Hidden`/`NoDisplay` entries before
the dedupe. It cannot be pointed at the curated dir alone, as
`tuigreet --sessions` is, so the packaged `hyprland-uwsm.desktop`
([ADR 0070]) would resurface, and a Hidden shadow file cannot mask it.

## Decision
- New `display_manager` value `noctalia-greeter`, its own Display Manager
  Adapter. `greetd` keeps meaning greetd + tuigreet.
- `auto`: `sddm` if the set has `kde`; else `noctalia-greeter` when
  `wayland_shell` is `noctalia`; else `greetd`; `none` for an empty set.
- Explicit `noctalia-greeter` is valid on any non-empty set (no lock).
- Installed with pacman from `extra` only; no AUR, no `extra-testing`.
- Both greetd adapters share the `config.toml` (`vt = 2`, `user = greeter`)
  and VT2 drop-in; each supplies only its `command`
  (`noctalia-greeter-session` here).
- The Hyprland adapter adds a pacman `NoExtract` for
  `usr/share/wayland-sessions/hyprland-uwsm.desktop` and removes any copy, so
  start-hyprland stays the sole Hyprland session under every greeter.
- v1 runs `noctalia-greeter-apply-appearance --setup-system` only; shell →
  greeter sync stays manual (polkit-authorized), no passwordless sync.

## Considered options
- **Greeter chosen inside the greetd adapter** — rejected: hides the choice
  from the operator, against [ADR 0069].
- **AUR now via vetted paru** — rejected: DM adapters run in the chroot with
  pacman; an AUR path adds trust surface for a package about to hit `extra`.
- **Accept the uwsm entry** — rejected: it black-screens under impermanence.

## Consequences
- The Package Resolver's `display-manager` set gains `greetd
  noctalia-greeter`; the Guided row gains the option.
- `/var/lib/noctalia-greeter` (state, last session) is not rolled back by
  impermanence.
