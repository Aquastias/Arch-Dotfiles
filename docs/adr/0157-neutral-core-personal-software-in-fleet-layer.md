# ADR 0157: Neutral core; personal software in the Fleet Layer

## Status
Accepted — implemented. Partly supersedes [ADR 0114] (where fleet
software lives) and the personal Guided Launch Presets of [ADR 0055] /
[ADR 0154]; amends [ADR 0112] (the pure profiles' user).

## Context
[ADR 0114] put every `desktop`/`laptop` package in Host Core, and User Core
grew the operator's userland (claude, pi, searxng, podman, nvim, zsh, …).
Host Core is also the Guided Installer's baseline, and the launch presets are
the operator (`eterniox`, `aquastias`, `Europe/Bucharest`, KDE, secure extras).
So anyone running Guided without picking a profile installs the operator's
personal machine. Worse, picking `minimal` or a `*-pure` profile in Guided
overlays the profile onto that baseline (`state * profile`): a resolved
profile with `packages.inherit: false` has no `packages` key, so the 105 Host
Core packages and the secure extras survive — `install.sh --profile minimal`
installs neither.

## Decision
Invariant: **a Guided session that never picks `desktop`/`laptop` installs
none of the operator's setup**, and a Guided profile pick yields the same
Effective Config as `install.sh --profile` (disks and secrets aside).

- **Fleet Layer** (`hosts/fleet/profile.jsonc`), folded Host Core → Fleet →
  `desktop`/`laptop` only. Takes Host Core's packages and host_programs,
  `environment.stock: false`, the full Font Catalog set and the mirror
  countries. Not installable: hidden from the Profiles picker, rejected by
  `--profile`.
- **Neutral Host Core**: `vm.swappiness` only.
- **Neutral User Core**: `/bin/bash`, no programs. The programs and
  `/bin/zsh` move to `users/aquastias`; a second human declares their own.
- **Neutral schema defaults**: `stock` → `true`; fonts → noto, dejavu,
  liberation; `mirror_countries` → empty (reflector ranks worldwide). Curated
  VM fixtures set `stock: false`. Other Install Defaults (zfs, lts,
  systemd-boot, multilib, pacman cosmetics) stay — generic and visible.
- **Neutral launch presets**: hostname `archlinux`, no preset user (Proceed
  blocks until one exists), timezone autodetected ([ADR 0118]), no desktop,
  Security & Backup extras off. Printing/bluetooth/power stay on.
- **Profile pick re-baselines** the Guided session: full reset, then the
  resolved profile becomes the baseline — no residue from core or earlier
  picks.
- **Pure profiles** use a neutral user; stock KDE drops papirus
  and the weather widget.
- **Package Resolver** also reports host_programs and user programs (by program
  name — a program's install script owns its packages), so `explain-packages`
  shows the whole install.
- **Guards**: a one-off golden diff proves `desktop`/`laptop` resolve
  unchanged; bats assert a blank Guided config holds nothing from Fleet or
  `aquastias`, and Guided pick ≡ `--profile` for every committed profile.

## Considered alternatives
- **Keep the workstation baseline in Guided** (visible, deselectable).
  Rejected: the operator does not want another user to inherit it by default.
- **Duplicate the software in `desktop` and `laptop`.** Rejected: the
  duplication [ADR 0114] removed.
- **A user-side fleet layer.** Rejected: it would need to know the host;
  `users/aquastias` is the only user who wants the set.
- **Neutralise only the Guided presets, not the schema.** Rejected:
  `--profile` with any non-fleet profile would still get curated defaults,
  and each default would have two owners.

## Consequences
- Adding fleet software is a Fleet Layer edit, not a Host Core one.
- The VM fixtures' `programs_exclude` of core programs become vacuous and go.
- A blank Guided session can no longer Proceed without creating a user.
- The install-time timezone fallback stays `Europe/Bucharest` ([ADR 0118]):
  it only fires when geo-IP autodetect fails, so a guest normally gets their
  own zone.
- `breeze-gtk` stays in stock KDE: it is a hard dependency of `plasma-meta`.
- Guided VM replays naming no user pick the neutral `stock` user; the VM
  throwaway users keep `nvim`, which User Core used to give them.
